# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-11-12

Первый рабочий релиз.

### Добавлено

- Анализ ссылки: обложка, название, автор, длительность и список форматов.
- Пресеты качества («Лучшее», «Лучшее MP4», «Минимальное», «Только аудио»)
  и выбор конкретной дорожки; для видео без звука аудио подставляется автоматически.
- Аудио: MP3, M4A, Opus, FLAC, WAV с настройкой качества.
- Очередь загрузок с прогрессом, скоростью, ETA, отменой и параллельными задачами.
- Постобработка: обложка и метаданные, субтитры, SponsorBlock, перепаковка
  в MP4/MKV/WebM.
- Cookies из браузера, прокси и ограничение скорости.
- Автоопределение Node.js/Deno/Bun/QuickJS и EJS-решателя для YouTube.
- Тёмная тема, drag & drop ссылок, горячие клавиши, сохранение настроек.
- Сборка `.exe` через PyInstaller и GitHub Actions.

### Исправлено

- Встраивание обложки больше не ломает загрузку в WAV и WebM: для неподдерживаемых
  форматов шаг пропускается с предупреждением.
- Добавлен `mutagen` — без него падало встраивание обложек в FLAC, Opus и M4A.
- Убраны дубли строк постобработки в журнале.
